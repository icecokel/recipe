# Recipe

개인 레시피를 모아두고 정리하는 저장소입니다.

## 목적

- 자주 만드는 요리의 재료와 조리 과정을 기록합니다.
- 다시 만들 때 필요한 팁, 대체 재료, 분량 조절 기준을 남깁니다.
- 새로운 레시피를 시도한 뒤 개선할 점을 누적합니다.

## 정리 방식

레시피를 추가할 때는 다음 내용을 중심으로 기록합니다.

- 요리 이름
- 재료와 분량
- 조리 순서
- 소요 시간
- 보관 방법
- 다음에 수정하거나 시도해 볼 점

## 권장 구조

```text
recipes/
  korean/
  western/
  dessert/
  drinks/
```

필요에 따라 카테고리는 자유롭게 추가하거나 변경합니다.

## 에스프레소 데이터

에스프레소 기록의 원천 데이터는 `vscoke-api`의 PostgreSQL DB와 `/espresso` API를 사용합니다.
이 저장소의 JSON 파일은 seed/export 및 API 실패 시 화면 폴백 용도로 유지합니다.
