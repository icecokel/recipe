# Recipe Page Purpose

## 목적

이 페이지는 개인 레시피와 에스프레소 추출 기록을 같은 저장소 안에서 분리해 보기 위한 정적 문서형 화면이다.

일반 레시피는 다시 만들기 쉬운 조리 정보에 집중하고, 에스프레소 기록은 같은 원두를 반복해서 추출하며 조건과 맛의 변화를 비교하는 데 집중한다.

## 범위

- `data/recipes.json`의 일반 요리 레시피를 레시피 페이지에서 보여준다.
- `data/espresso-recipes.json`의 원두별 추출 기록을 에스프레소 페이지에서 보여준다.
- 화면은 `index.html`, `styles.css`, `app.js`만 사용한다.
- 빌드 도구, 프레임워크, 외부 라이브러리는 사용하지 않는다.
- JSON 파일을 직접 수정하거나 저장하는 기능은 포함하지 않는다.

## 구분 기준

### 레시피

레시피 페이지는 재료와 조리 순서가 핵심이다. 각 항목은 다음 정보를 우선해서 보여준다.

- 이름
- 태그
- 재료
- 조리 순서
- 출처 링크

### 에스프레소

에스프레소 페이지는 완성된 조리법보다 추출 로그를 누적하는 공간이다. 각 항목은 원두를 기준으로 묶고, 그 안에 회차별 조건과 결과를 보여준다.

- 원두 이름
- 장비와 목표
- 회차별 도징, 추출량, 온도, 시간 같은 조건
- 맛 결과
- 판단
- 다음 액션
- 다음 테스트 방향

## 사용 방식

사용자는 로컬 정적 서버로 페이지를 열고, 상단의 레시피와 에스프레소 전환 버튼으로 두 종류의 기록을 분리해서 확인한다.

데이터는 JSON 파일을 기준으로 읽기 전용으로 표시한다. 새 항목을 추가하거나 내용을 고칠 때는 JSON 파일을 직접 수정한다.

## 디자인 원칙

- 장식보다 가독성을 우선한다.
- 한 화면에서 목록을 빠르게 훑고 세부 내용을 바로 읽을 수 있게 한다.
- 모바일과 데스크톱에서 모두 읽기 쉽게 단순한 단일 흐름을 유지한다.
- 데이터가 비어 있거나 일부 필드가 없어도 화면이 깨지지 않게 한다.
